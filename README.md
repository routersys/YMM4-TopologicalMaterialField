# トポロジー誘導材質合成 for YMM4

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](#)
[![.NET](https://img.shields.io/badge/.NET-10.0-purple.svg)](#)
[![Release](https://img.shields.io/github/v/release/routersys/YMM4-TopologicalMaterialField.svg)](https://github.com/routersys/YMM4-TopologicalMaterialField/releases)

---

YukkuriMovieMaker4（YMM4）上で動作する、現在のフレームから色と明暗の領域構造を求め、選択した材質の色分布、微細模様、凹凸、照明を合成する映像エフェクトプラグインです。
履歴フレーム、参照画像、学習済みモデルを使わず、入力された一枚の映像だけを処理します。
陶器、鉱物、酸化金属、羊皮紙、氷晶、布地の6種類から材質を選択できます。
強さ、位相尺度、分布輸送、凹凸、照明などの11項目はアニメーションに対応しています。

## 概要

本プラグインはYMM4の映像エフェクトとして動作し、エフェクトの種類一覧では「トポロジー誘導材質合成」として表示されます。カテゴリはフィルタリングと装飾です。

入力色をOklab色空間へ変換し、平滑化した明度場で各画素の上昇側と下降側の到達点を求めます。到達点の組が同じ画素を一つの領域として扱い、領域境界、隆起、谷、隣接関係を材質合成の制約に使います。

各領域では、Oklabの色成分と局所構造を8方向へ射影し、決定論的に選んだ領域内標本から経験分布上の位置を求めます。その位置を選択した材質の分布へ写し、入力の領域構造を残しながら色と明暗を変換します。続いて、領域を越えない反応拡散で微細模様を作り、領域内の接続関係を使ったscreened Poisson再構成で階調を統合します。再構成した明度場から表面法線を求め、材質ごとの拡散反射と鏡面反射を加えて出力します。

計算はComputeSharpの計算シェーダーで実行します。YMM4のDirect3D 11側とComputeSharpのDirect3D 12側は、共有テクスチャと共有フェンスで接続します。通常のフレーム処理ではCPUへの画素読み戻しとCPUからの画素再転送を行いません。入力と出力のアルファ値は維持されます。

このエフェクトはAviUtl向けのEXO出力には対応していません。

## インストール方法

1. [Releases](https://github.com/routersys/YMM4-TopologicalMaterialField/releases/latest)ページから最新のプラグインファイル（`.ymme`）をダウンロードしてください。
2. YMM4が起動していないことを確認し、ダウンロードしたファイルを実行してインストールします。
3. YMM4を起動し、タイムライン上のアイテムに映像エフェクトを追加します。
4. 映像エフェクトの種類として「トポロジー誘導材質合成」を選択してください。

## 主な機能

### 1. 現在フレームの領域解析

現在のフレームをOklab色空間へ変換し、明度場をエッジ保存平滑化します。各画素から近傍の明るい方向と暗い方向をたどり、上昇側と下降側の到達点を求めます。同じ組へ到達する画素を同じ領域として扱うため、外部マスクや手動の領域指定を必要としません。

位相尺度は明度場を平滑化する回数と空間重みを調整します。特徴閾値は、近傍との差が小さい勾配を停留点として扱う範囲を決めます。

### 2. 領域内の材質分布合成

各画素のOklab成分と隆起・谷の局所構造を8方向へ射影し、同じ領域から選んだ標本との順位を求めます。順位を材質ごとの中心色と分布幅へ写すことで、領域境界を保ちながら材質固有の色と階調へ変換します。

分布輸送は入力から材質分布へ移す強さを調整します。色変動は材質の中心色へ近づける量と色幅を調整します。

### 3. 領域境界に従う微細模様

材質ごとに異なる係数を使った反応拡散で微細模様を生成します。初期状態はシード、座標、領域の上昇先と下降先から決定論的に決まります。反応拡散の近傍参照は同じ領域内に制限されるため、模様は領域境界を越えて混ざりません。

模様サイズは反応拡散の標本間隔と初期核の大きさを調整します。模様強度は、生成した模様を色と凹凸へ反映する量を調整します。

### 4. 階調再構成と表面照明

材質分布、反応拡散模様、領域の隆起・谷・境界を統合した目標明度を作り、同じ領域内の上下左右だけを接続したscreened Poisson方程式をJacobi法で解きます。再構成した明度の勾配から表面法線を求め、光源方向に応じた拡散反射と材質別の鏡面反射を合成します。

再構成は階調を統合する強さ、凹凸は表面法線の強さを調整します。光源角度と光源高度で照明方向を指定できます。

### 5. 材質と品質の選択

| 材質 | 特徴 |
|---|---|
| 陶器 | 滑らかな暖色の素地と硬い鏡面反射 |
| 鉱物 | 色幅が広い結晶質の分布 |
| 酸化金属 | 金属反射と暖色の酸化層 |
| 羊皮紙 | 暖色の繊維質分布と柔らかな反射 |
| 氷晶 | 寒色の透明感と鋭い鏡面反射 |
| 布地 | 交差する織り目と低い鏡面反射 |

品質は領域内標本数、反応拡散の反復回数、Poisson再構成の反復回数をまとめて切り替えます。

| 品質 | 領域内標本数 | 反応拡散 | Poisson再構成 |
|---|---:|---:|---:|
| 標準 | 16 | 24回 | 32回 |
| 高品質 | 32 | 40回 | 48回 |
| 最高品質 | 48 | 64回 | 80回 |

## 制限事項

- AviUtl向けのEXO出力には対応していません。
- Direct3D 12デバイスを取得できない場合や、YMM4が使うDirect3D 11デバイスとの共有テクスチャおよび共有フェンスを作成できない場合は、エフェクトを適用せず入力映像を表示します。
- 解析対象は現在のフレームだけです。履歴フレーム、外部画像、深度情報、学習済みモデルは使用しません。
- 処理量とGPUメモリ使用量は入力映像の画素数に応じて増えます。

---

## 注意事項

- 処理負荷: 最高品質は領域内標本数と反復回数が最も多いため、高品質と標準より処理負荷が高くなります。位相尺度を上げると明度場の平滑化回数も増えます。
- シードと再現性: 領域内標本と反応拡散の初期状態は、シード、画素座標、領域の到達点から決定論的に算出します。時間値は乱数の生成に使用しません。
- 透明部分: 入力のアルファ値を出力へ維持します。完全に透明な画素は材質合成の対象から除外されます。
- 更新通知: エフェクトを最初に生成したときに、YMM4の実行中に一度だけ新しい正式版を確認します。更新情報を取得できない場合は通知せず、そのまま動作します。プレリリースは通知の対象に含めません。
- 本プラグインを使用する前に、YMM4のプロジェクトファイルのバックアップを作成することを推奨します。
